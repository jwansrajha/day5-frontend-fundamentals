# Day 5 - Web Fundamentals Review

A very small static practice page for Day 5 of my internship training.

## Topics covered
- **HTML:** page structure and semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`).
- **CSS:** colors, spacing, basic layout, and Flexbox (`display: flex`, `gap`, `flex-wrap`).
- **JavaScript:** variables, an array, a loop, a condition, a function, a click event, and changing text with the DOM.

## Files
- `index.html` - page structure
- `style.css` - basic styling
- `script.js` - one simple button interaction

## How to run
Open `index.html` in a web browser. No installation, framework, or server needed.
